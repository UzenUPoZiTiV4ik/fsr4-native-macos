# Инструкция: FSR 4.1.1 на Mac

## 1. Что нужно

- Mac на Apple Silicon (быстрее всего на M5, подробнее: [HARDWARE.md](HARDWARE.md))
- macOS 26+, Xcode 26+ (бесплатно в App Store), Python 3
- Для игр: CrossOver 24+ и Rosetta 2

## 2. Установка в CrossOver через приложение (проще всего)

![FSR4 Installer](images/installer.png)

1. Скачайте **FSR4-Installer-v1.8.dmg** из
   [последнего релиза](https://github.com/UzenUPoZiTiV4ik/fsr4-native-macos/releases/latest),
   откройте его и перетащите **FSR4 Installer** в «Программы».
2. Первый запуск. Приложение не нотаризовано Apple, поэтому macOS его
   блокирует. Откройте **Системные настройки → Конфиденциальность и
   безопасность**, внизу нажмите **Всё равно открыть** (Open Anyway) и подтвердите паролем.
   Или одной командой в Терминале:

   ```sh
   xattr -dr com.apple.quarantine "/Applications/FSR4 Installer.app"
   ```

3. Раздел **Что нужно**. Приложение проверяет Mac. Всё, чего не хватает,
   исправляется кнопкой в той же строке:

   | Пункт | Кнопка |
   | --- | --- |
   | Xcode 26+ | **Открыть App Store**, если Xcode нет. **Настроить…**, если он установлен, но не выбран или не принята лицензия (спросит пароль) |
   | Metal Toolchain | **Скачать**: компонент Xcode для компиляции шейдеров |
   | Rosetta 2 | **Установить** (спросит пароль) |
   | CrossOver 24+ | Ссылка на сайт CodeWeavers. CrossOver должен лежать в «Программах» |

   После установки Xcode нажмите ↻ справа от заголовка, чтобы проверить снова.
4. Полностью закройте игру и её бутылку. Если бутылка запущена, приложение
   предупредит: бутылка читает настройки только при старте.
5. Выберите бутылку и **режим при запуске**: FSR 4.1 Lite (быстрее) или
   FSR 4.1 (лучше качество). Оставьте включённой **панель FSR 4**, если хотите
   менять режим прямо в игре.
6. Нажмите **Установить в «…»**. Установка занимает около минуты: сборка
   хука, патч копии D3DMetal, компиляция шейдеров и проверка результата на
   тестовом кадре. Ход виден в строке состояния и в разделе **Лог**.
7. Запустите игру в CrossOver и включите в настройках графики **DLSS**.
   Первый запуск компилирует шейдеры под разрешение игры, это до минуты.

Переустановка с другими настройками или после обновления приложения: та же
кнопка. Удаление: **Удалить…**, бутылка вернётся к D3DMetal из CrossOver.
Сами игры, сохранения и CrossOver.app не меняются.

Файлы приложения лежат в `~/Library/Application Support/fsr4-native-macos`
(кнопка **Показать файлы**). Удалить приложение полностью: сначала
**Удалить…** во всех бутылках, затем удалите эту папку и само приложение.

## 3. Установка из исходников (Терминал)

Сборка:

```sh
xcodebuild -downloadComponent MetalToolchain
make -B
tools/bin/fsr4mac --backend-info
```

Последняя команда показывает, какой режим GPU будет использован.

Установка:

1. Полностью закройте игру и её бутылку.
2. Выполните:

   ```sh
   python3 tools/crossover/crossover_fsr4.py install --panel --profile lossy
   ```

   Если бутылка одна, она выбирается сама. Если их несколько, добавьте
   `--bottle "Имя бутылки"` (или путь к `cxbottle.conf`).
3. Запустите игру и включите в настройках **DLSS**.

## 4. Режимы в игре

Появится панель **FSR 4**. Выберите режим:

| Режим | Что это |
| --- | --- |
| FSR 4.1 Lite | Самый быстрый (по умолчанию) |
| FSR 4.1 Lite 2 | Lite с обученными слоями; появляется после `make lossy2-weights` |
| FSR 4.1 | Полное качество |

Режим и резкость меняются сразу, перезапуск не нужен. Старая модель 4.0.2
в панели не показывается: её можно включить только при сборке из исходников
через `FSR4_PROFILE=fsr4` (см. ниже).

## 5. Как всё вернуть

В приложении: выберите бутылку и нажмите **Удалить…**. Из Терминала:

```sh
python3 tools/crossover/crossover_fsr4.py restore --bottle "/path/to/cxbottle.conf"
```

Затем перезапустите бутылку. Сам CrossOver.app установщик не изменяет.

## 6. Если что-то не так

- «Приложение повреждено» или «не удаётся проверить разработчика»: см. шаг 2
  раздела 2 (`xattr`).
- Установка не удалась: откройте раздел **Лог** и нажмите **Скопировать лог**,
  приложите его к issue на GitHub.
- Лог игры: `dist/crossover/hook.log` (в приложении кнопка **Лог игры**).
- Шлейфы при движении: нажмите в панели **Record diagnostics**, подвигайте
  камеру до сообщения «Done». Запись появится в `dist/crossover/captures/`.
  Анализ:

  ```sh
  python3 tools/diagnostics/analyze_motion_capture.py dist/crossover/captures/<каталог> --json motion-analysis.json
  ```

- Подробности: [CROSSOVER.md](CROSSOVER.md).

## Для продвинутых

### Настройки через окружение бутылки

Сохранённый выбор в панели важнее переменных. Чтобы использовать только
переменные, задайте `FSR4_SETTINGS=none`.

| Переменная | Значения |
| --- | --- |
| `FSR4_PROFILE` | `lossy` (по умолчанию), `exact-fast`, `exact`, `fsr4` |
| `FSR4_VERSION` | `4.1.1` (по умолчанию) или `4.0.2` |
| `FSR4_MODEL` | `auto`, `i8mpp`, `simd` (M1–M4, по умолчанию там), `scalar`, `reference` |
| `FSR4_SHARPNESS`, `FSR4_RCAS` | Резкость (по умолчанию RCAS 0.4) |
| `FSR4_OPTIMIZE` | `1` по умолчанию, `0` отключает оптимизации |
| `FSR4_COMPILE` | `0` запрещает компиляцию недостающих шейдеров |

`exact` (битово-точный эталон) доступен только через `FSR4_PROFILE`.

### Запуск без игры

```sh
tools/bin/gen_testcase testcases/quality411 quality 1280 720 1920 1080 8
tools/bin/fsr4mac testcases/quality411 out/lossy --profile lossy
tools/bin/fsr4mac testcases/quality411 out/bench --profile lossy --bench 10
```

Результат: PNG, `.bin` и `run.json`. Формат входа:
[TESTDATA.md](../TESTDATA.md), [FSR411_INPUT_CONTRACT.md](FSR411_INPUT_CONTRACT.md).
Методика замеров: [BENCHMARK.md](../BENCHMARK.md).
