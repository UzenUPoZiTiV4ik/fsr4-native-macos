# v4.2 - ANR FG-V.B20 kernel/runtime speedups and FSR 4.1.2 PRE/POST optimizations

Quit the game, install the new DMG or CrossOver ZIP, then restart the game.
FSR 4.1.2 shader cache keys advance to `v4` / `lossy5` (shaders rebuild once per
resolution on first launch; weight pins are unchanged since v3.3). To pick up
the new ANR kernel optimizations on an existing local `FG-V.B20` runtime, re-run
`tools/anr/prepare.py --addon /path/to/anr-fg-V.B20-addon.zip --output build/anr_runtime_v20`.
ANR weights and compiled shaders stay local under `build/` and are never
packaged in this repository or release archives.

## Measured speedups on Apple M5 (`lowpowermode 0`, battery)

All numbers below are from interleaved A/B runs on an idle fanless Apple M5
with `lowpowermode 0` (battery power, continuous GPU execution for ANR `p10`
without compositor preemption gaps; standalone/synthetic benchmarks, not
guaranteed game FPS).

### ANR FG-V.B20 (1080p PQ10, Metal 4)

| Metric (1080p PQ10) | v4.1 (`8308b41`) | v4.2 (`crossover-v4.2`) | Change |
| --- | ---: | ---: | ---: |
| **ANR 2x** continuous GPU (`p10`) | 3.42 ms | **3.18 ms** | **-0.24 ms (-7.1%)** |
| **ANR 3x** continuous GPU (`p10`) | 5.07 ms | **4.69 ms** | **-0.38 ms (-7.5%)** |
| **Live compute encoders / frame** | 5 (2x) / 7 (3x) M4, 4 / 6 M3 | **1 encoder** | Full live frame fused |
| **Graph scratch buffers** | 94 buffers | **49 buffers** | **-19.6 MB** (1080p), **-34.8 MB** (1440p), **-77.9 MB** (4K) |
| **Manifest read-only buffers** | 9 / 334 (325 writable) | **205 / 334** (129 writable) | Static `const device` qualification across all 33 kernels |
| **`verify.py` PSNR** (`t=0.5` / `t=0.75`) | >= 72.0 / >= 71.0 dB | **73.10 / 72.30 dB** | Passes both quality gates |

## What changed

### ANR FG-V.B20 shaders and runtime

- **`final_trust_image_fill_*` threadgroup staging & `simd_ballot`** (`tools/anr/opt_final_trust.py`):
  stages the 18x6 half-res flow/trust/validity footprint in threadgroup memory
  across PQ10, sRGB8, and scRGB16, replaces the row-hole barrier reduction with
  `simd_ballot`, and simplifies interior warp coverage while preserving exact
  RGBA16F hardware gain filtering.
- **Lock-free cell binning for `phase_gather_sil_pd` / `reverse_gather` and native `trust_phase_neither`**
  (`tools/anr/opt_gather.py`): replaces threadgroup float CAS splat loops with
  single-atomic-exchange linked-list cell binning + FP32 output gather (keeping
  the original overflow fallback intact), compacts the 40-stride tile to
  32-stride, aliases dead tile storage for final reductions, and rewrites
  `trust_phase_neither` with register 4-tap sampling and SIMD 4x2 reductions
  (512 B threadgroup memory).
- **SIMD32 reductions & static `const device` qualification across all 33 kernels**
  (`tools/anr/opt_msl.py`): static write analyzer drops falsely writable buffer
  bindings from 325 to 129 (205 read-only), and specializes `trust_half_image_pick_*`
  (14,336 -> 1,088 B TG, 1 barrier) and `pair_inputs_*` (22,848 -> 4,288 B TG,
  2 barriers) with Apple SIMD32 shuffles and `precise::divide`.
- **Single-encoder live frame fusion, scratch aliasing, and cached static arguments**
  (`src/anr/anr_runtime.mm`, `src/anr/anr_live.mm`, `src/anr/anr_helpers.metal`):
  fuses `import + pair + phase (+ export) + retire` into 1 compute encoder per
  frame on both Metal 4 and Metal 3 (`FSR4_ANR_FUSE_GROUPS=0` opt-out), packs
  non-overlapping graph buffers into a safe scratch arena preserving pair-to-phase
  liveness for 3x (`94 -> 49` buffers, saving 19.6 / 34.8 / 77.9 MB at
  1080p / 1440p / 4K; `FSR4_ANR_SCRATCH_ALIAS=0` opt-out), sets exact
  `maxTotalThreadsPerThreadgroup` on V.B20 PSOs, and caches static argument
  buffers per slot/parity.

### FSR 4.1.2 PRE/POST shaders and Metal 4 host path

- **Compact `post_reuse_tile` union & inline 12-byte color reads**
  (`tools/fsr412/optimization.py`, `tools/fsr412/lossy_shaders.py`): aliases
  disjoint-lifetime reuse luma/motion data against `packed_float3` color tiles
  to drop `post_reuse_tile` threadgroup memory from 25,888 B to 9,408 B (-63.7%)
  and `post_tile` / `post_full_tile` from 12,544 B to 9,408 B (-25.0%), computes
  neighbor luma once per texel, uses inline 12-byte `__builtin_memcpy` into
  `float3` to keep bit-exact contraction, and reuses the winning dilated depth
  in register inside `Fsr412LossyRecord`.
- **Guarded 16x16 `pre_tile` / `pre_reuse_tile` & Lossy exposure shortcut**
  (`tools/fsr412/pre_opt.py`, `tools/fsr412/compile_fsr412.py`): stages
  `r_prepared_color` (clamped) and `r_depth` (unclamped OOB=0) in a 4 KB 16x16
  threadgroup tile on Apple10 (`FSR4_LITE_PRE_TILE=0/1` toggle), reads both
  auto-exposure values via one `gather`, and skips the 6x `exp`/`log` MuLaw
  round-trip when exposure is unchanged in Lossy modes (strict Lite stays
  bit-exact).
- **Metal 4 host overhead reduction** (`src/fsr41x/fsr411_runtime.h`,
  `src/fsr41x/fsr412_session.inc`): caches per-slot `MTLResidencySet` contents
  by ordered strong key so steady frames skip redundant commits, replaces
  Foundation argument table containers with C++ storage, marks transient buffers
  untracked on Metal 4 (preserving tracked resources on classic switch-back),
  and coalesces independent copy/pad barriers. Cache keys advance to `v4` / `lossy5`.

## Validation

- **ANR**: `tools/anr/verify.py` (73.10 dB at `t=0.5`, 72.30 dB at `t=0.75`),
  `tools/anr/manifest.py`, `make test-anr-input`, `make test-anr-ui` (16/16
  Metal 3 and Metal 4), `make test-anr-motion` (2x/3x classic and Metal 4),
  `make test-anr-live` (SDR + HDR, classic and Metal 4), `make test-anr-startup`,
  21 Python unit tests, and `opt_msl.py` doctests all passed.
- **FSR 4.1.2 & core**: `make test` (all C++, Swift installer, panel, Netal,
  ANR, and 249+ Python unit tests), `make test-fsr412-optimization` (byte-exact
  tiled vs untiled POST and PRE across Lite, Lossy, and new-look on classic and
  Metal 4), `make test-fsr412-lossy` (48 backend/state parity groups), and
  `make test-fsr412-new-look` all passed.
