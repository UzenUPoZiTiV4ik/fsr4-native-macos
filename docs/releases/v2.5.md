M5 INT8 tuning and the SIMD/Winograd optimization work in one release.

### M5
- Register-only CNB, FNB32/64, CT32/64 and DS32 chains remove intermediate shared-memory storage without changing weights or integer arithmetic.
- An on-device register-layout probe and exact dispatch-contract checks guard every fast kernel. Unsupported layouts keep the established implementation. Set `FSR4_MPP_OPTIMIZE=0` before launch to opt out.
- FNB64 neural passes measured about 25-26% faster in isolation. Whole-frame gains are smaller and workload-dependent, not a game FPS guarantee. The combined public replay and its method are recorded in `docs/FSR_M5_INT8_OPTIMIZATION.md`.

### SIMD optimization included
- Includes the pre-M5 SIMD work: vector integer epilogues, smaller convolved/bypass input windows and actual 128-thread pipeline limits.
- Includes exact, CPU-bound-checked Winograd F(2x2,3x3) for SIMD CNB16/FNB32: 16 matrix products per bank instead of 36. GPU verification and the direct-kernel fallback remain in place.
- The recorded forced-SIMD M5 replay showed roughly 14-16% less inference-frame GPU time with Winograd. This is not a measured M1/M2/M3/M4 speed claim; those chips still need physical-hardware benchmarks.

### Compatibility and checks
- Retains CrossOver 26 support, reversible framework install/restore, the existing tiled POST path, retrained FSR 4.1.2 Lossy and the adjustable pixelization fix.
- The working branch's `int8-lite-hair` / `--hair-fix` names are accepted as aliases for the existing optional pixelization fix. Plain Lite remains the default.
- CPU policy/math tests, MPP fast and forced-fallback CPU-oracle checks, SIMD/Winograd checks, classic Metal/Metal 4 full-frame byte identity and the x86_64 live hook under Rosetta passed.
- Slower or non-identical experiments are not enabled. Windows driver DLLs are neither bundled nor executed.

### Install/update
Open **FSR4-Installer-v2.5.dmg**, or unpack **fsr4-mac-v2.5-crossover.zip** and follow `INSTALL.md`. Quit the game and its bottle, run Install again, then restart the game to load the updated hook.

The installer is ad-hoc signed, not notarized; macOS may require **System Settings -> Privacy & Security -> Open Anyway** on first launch.
