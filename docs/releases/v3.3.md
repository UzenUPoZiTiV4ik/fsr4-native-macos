# v3.3 - November Lossy weights and macOS 27 hook fix

Quit the game, install the new DMG or CrossOver ZIP, then restart the game. The default profile is FSR 4.1.2 INT8 Lite. For the optional Lossy profiles, refresh the external data in the installation root. The release bundles the base AMD Lite assets. The trained weights are a separate download.

| Profile | Prepare | What changed |
| --- | --- | --- |
| `int8-lite-lossy` (4.1.2) | `make lite-lossy-weights` | Verifies all five identical normal-preset weight buffers, recovers the POST biases from two resolution tiers, and applies the updated intermediate rounding. Ultra Performance uses its separate AMD initializer. Above 4K the port uses base Lite. |
| `lossy2` (4.1.1 runtime) | `make lossy2-weights` | Imports six retrained passes from 18 shader containers. All three resolution tiers must agree. |
| `int8-lite-lossy-original` (CLI) | `make original-lossy-weights` plus the original shader bundle | Keeps the November 1 graph, its matching weights and nearest-even rounding in separate caches. |

Both current importers verify the RX 6000 ZIP and DLL from `dll-2026-11-22`. This archive avoids the additional RX 7000 driver-selection sections. The upstream particle and dark-speck rules have yet to be ported to the adjusted Metal path. The optional new-look filter includes the moving-edge corrections from PRs #23 and #25. The original route includes the skip and rounding checks from PR #24. [Upstream release](https://github.com/zgauthier2000/fsr4-shader-performance-overrides/releases/tag/dll-2026-11-22) · [Author's extraction notes and hashes](https://github.com/UzenUPoZiTiV4ik/fsr4-native-macos/issues/20#issuecomment-7082857439)

The MetalFX hook probes both depth getter names on macOS 27. On macOS 27.0.1 with an Apple M5, the CrossOver installer loaded the x86_64 hook under Rosetta and its 720p-to-1080p live output matched the command-line reference at every pixel. The Metal 3 and Metal 4 Lite Lossy and new-look backend comparisons passed. These checks cover synthetic frames. Game FPS and game image quality have not been measured for v3.3.
